About Python(hello honey!)
Python was created by Guido van Rossum in 1991.
It focuses on code readability and uses indentation instead of braces.
Key Features
Interpreted (no need to compile)
Dynamically typed
Object-oriented + functional
Large standard library
Beginner-friendly
Supports AI/ML, automation, scripting
